# v1.0.0 · 微信消息任务汇总器与展示台

**发布日期**：2026-09-30

首个公开发布版本。读取本机微信 / QQ 聊天记录，用大模型抽取任务，以磁贴墙集中展示与分类管理。

---

## 核心功能

- **自动抓取任务**：读取微信（经 `wechat_exp`）与 QQ 聊天记录，交给 LLM 抽取
  任务名称、主题、类型、负责人、接头人、起止时间、材料清单。
- **附件内容读取**：聊天中的文件（`.docx` / `.xlsx` / `.pdf` / `.txt` / `.md`）与链接
  会读取正文一并判断。
- **手动添加 / 编辑任务**：可新建任务、编辑已有任务，改动自动保存；名称/主题可由 AI 生成。
- **磁贴墙展示**：类似 Windows 10 开始菜单动态磁贴，可拖拽排列。
- **五类状态管理**：进行中 / 未开始 / 已完成 / 已过期 / 已删除（回收站，可恢复）。
- **任务自动去重**：同一任务被多人在多群发布时自动合并发布人。
- **多选批量操作**、**系统托盘常驻**、**按账号隔离打开链接**。
- **本地加密**：PBKDF2-HMAC-SHA512 + AES-256-GCM，数据不出本机。

本软件**不打包、不分发**任何第三方工具，运行时需要你**自行下载**：

| 工具 | 用途 | 下载地址 |

> 不会编译也没关系——**微信功能完全不受影响**，QQ 只是可选增强。

## 已知问题与限制

- 密钥提取存在「窗口期」，需要微信/QQ 处于登录状态。
- QQ 数据库解密与消息解析属逆向成果，QQ 大版本更新后可能失效。
- 图片不做 OCR；扫描件 / 加密 PDF 可能取不到文字。
- 任务抽取质量取决于所选模型；未配置 API Key 时退回规则抽取（磁贴会标「规则」角标）。
- 安装包未做代码签名，首次运行可能被 SmartScreen 拦截，选「更多信息 → 仍要运行」即可。
