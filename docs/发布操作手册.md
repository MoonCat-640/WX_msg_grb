## 二、你需要手动执行的动作

### 步骤 1：在 GitHub 网页创建空仓库

- 仓库名：`WX_msg_grb`
- **不要**勾选 "Add a README / .gitignore / license"（本地已有，避免冲突）
- 可见性：按你的意愿（Public / Private）

### 步骤 2：添加远程仓库并推送

**本地仓库已经建好了**（`git init` + 首次提交已完成，分支 `main`，共 117 个文件）。
你只需要添加远程地址并推送：

```powershell
cd E:\Files\Programmes\WX_message

git remote add origin https://github.com/MoonCat-640/WX_msg_grb.git
git push -u origin main
```

> ℹ️ 提交身份已配置为 `MoonCat-640 <MoonCat-640@users.noreply.github.com>`（仓库级，不影响其它项目）。

<details>
<summary>如果你想从头核对一遍（可选）</summary>

```powershell
git log --oneline          # 应看到 1 条提交
git ls-files | wc -l       # 应为 117
git status                 # 应为干净

# 确认敏感内容确实没被纳入版本库（以下都应输出路径，表示"被忽略"）
git check-ignore -v node_modules reference D; .npmrc
```
</details>

> ⚠️ **推送前请再看一眼** `git status` 与 `git ls-files`：应只包含
> `src/ scripts/ build/ docs/` 与根目录的
> `README.md / CHANGELOG.md / LICENSE / .gitignore / .gitattributes / package*.json / electron-builder.yml / tsconfig*.json / electron.vite.config.ts`。
> 若看到 `node_modules/`、`reference/`、`*.db`、`out/`，说明 `.gitignore` 没生效，**先停下排查**。

### 步骤 3：打 tag 并创建 Release

素材已备好在 **`D:\Applications\WX_message\release-assets\`**：

```
Setup.exe                     ← 上传这一个即可
README.md                     ← 随附（可选）
release-notes-v1.0.0.md       ← 直接作为 Release 正文
SHA256SUMS.txt                ← 校验和（可选）
```

**方式 A（网页）**：
1. 仓库 → Releases → *Draft a new release*
2. Tag：`v1.0.0`，Target：`main`
3. 标题：`v1.0.0 · 微信消息任务汇总器与展示台`
4. 正文：粘贴 `release-notes-v1.0.0.md` 的内容
5. 附件：上传 `Setup.exe`（**不要**上传 `tools\` 里的 wechat_exp / QQFlow）
6. Publish release

**方式 B（gh CLI）**：

```powershell
cd D:\Applications\WX_message\release-assets
gh release create v1.0.0 Setup.exe `
  --title "v1.0.0 · 微信消息任务汇总器与展示台" `
  --notes-file release-notes-v1.0.0.md
```

## 三、后续发版流程（备忘）

```powershell
# 1) 改版本号（package.json 的 version）
# 2) 更新 CHANGELOG.md，新增 docs/release-notes-v<版本>.md
# 3) 重新构建并部署
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\build-release.ps1
# 4) 整理 Release 附件
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\prepare-release.ps1 -Version <版本>
# 5) 打 tag 并创建 Release（同上）
```

## 四、红线提醒

1. **永远不要提交/上传真实聊天数据**（`*.db`、`*.silk`、`D;\`、`WXdecoded\` 等）。
   `.gitignore` 已挡住，但提交前请肉眼确认 `git status`。
2. **永远不要上传 `wechat_exp` / `QQFlow`**。它们不随本项目分发，各自遵循自身许可；
   在 README 里指路到其 GitHub 仓库即可。
3. **不要在提交内容里写入真实 wxid、账号、密钥**。调试用的假数据请使用
   `wxid_example...` 之类明显占位的形式。
4. 安装包**未做代码签名**，用户首次运行会被 SmartScreen 拦截属正常现象，README 已说明。
