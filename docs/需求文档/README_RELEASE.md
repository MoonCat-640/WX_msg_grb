## 发布前收尾任务书

### 任务目标

项目开发与测试已完成，进入分发阶段。请完成以下收尾工作，确保仓库、文档、安装包达到可公开分发的标准。

------

### 一、LICENSE 与合规

1. **在仓库根目录创建 `LICENSE` 文件**，内容为标准 MIT License 文本，版权人写你的名字（或 GitHub ID），年份写当前年份。
2. **在 README 中增加“许可证”章节**，明确说明：
   - 本项目采用 MIT License。
   - 第三方依赖 `QQFlow`、`wechat_exp` 遵循各自许可证，本项目不打包、不分发这两个工具。
   - 用户需自行从对应 GitHub 仓库下载并安装。

------

### 二、README 重写

README 是给使用者和贡献者看的第一份文档，请按以下结构重写：

1. **项目简介**：一句话说明软件用途（读取微信/QQ 消息，提取任务，以磁贴形式展示）。
2. **功能特性**：分点列出核心功能（自动抓取、手动添加/编辑、任务分类、多选清除、系统托盘等）。
3. **截图或演示**：如有，放 1-2 张主界面截图。
4. **依赖说明**：
   - 明确列出 `wechat_exp`、`QQFlow` 为外部依赖，附上 GitHub 链接。
   - 说明需要用户自行下载并配置路径。
5. **安装步骤**：从下载 Setup.exe 到首次运行的完整流程。
6. **使用指南**：登录、选择联系人/群聊、配置 API Key、抓取任务、手动添加/编辑任务的基本操作。
7. **已知限制**：密钥窗口期、免费中转的稳定性、图片暂不支持 OCR 等。
8. **隐私声明**：本地运行，不上传任何用户数据。
9. **许可证**：MIT License，第三方依赖遵循各自许可证。
10. **贡献指南**（可选）：欢迎 Issue 和 PR。

------

### 三、GitHub Release 准备

1. **打 tag**：使用语义化版本号，例如 `v1.0.0`。
2. **写 Release Notes**，包含：
   - 版本号与发布日期。
   - 核心功能概述。
   - 依赖提醒（需自行下载 `wechat_exp`、`QQFlow`）。
   - 安装包下载链接。
   - 已知问题与限制。
3. **上传安装包**：将 Setup.exe 作为 Release 附件上传。

------

### 五、安装包检查

1. Setup.exe 只安装主程序，**不打包** `wechat_exp`、`QQFlow`。
2. 安装向导中包含“依赖检查”步骤：检测系统中是否已存在这两个工具，若不存在则提示用户前往 GitHub 下载，附上链接。
3. 安装完成后生成主程序快捷方式，确认可正常启动。
