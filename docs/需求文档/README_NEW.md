## 项目开发任务书

### 项目名称

微信消息任务汇总器与展示台（WX_msg_grb）

### 技术栈建议

- **桌面框架**：Electron（跨平台、UI 灵活）或 WPF（Windows 原生、性能好）
- **语言**：TypeScript/JavaScript（Electron）或 C#（WPF）
- **本地存储**：SQLite（加密存储用 SQLCipher 或应用层 PBKDF2 加密）
- **LLM 调用**：统一 HTTP 客户端，支持多平台 API
- **微信数据读取**：集成 `wechat_exp_2.10.20260925_2.exe`（参考仓库：`https://github.com/...`，请根据实际仓库地址填写）

### 核心模块与实现要求

#### 模块 1：安装程序

- 使用 NSIS 或 Inno Setup 制作 `Setup.exe`
- 请求 UAC 管理员权限
- 支持选择语言、安装路径、当前用户/全体用户、是否加入 PATH
- 安装完成后创建指向 `WX_msg_grb.exe` 的快捷方式

#### 模块 2：多平台登录

- 支持微信、QQ、企业微信三平台，每平台最多 2 个账号
- 微信/企业微信：扫码登录（调用平台开放接口或模拟扫码流程）
- QQ：扫码或账号密码登录
- 登录成功后，账号信息用 **PBKDF2** 加密存储
- 提供“完成”和“取消”按钮

#### 模块 3：联系人与群聊选择

- 登录后自动识别已登录账号
- 以标签页形式展示每个账号的联系人和群聊
- 支持多选，点击确认后进入下一步

#### 模块 4：聊天记录读取

- **调用 `wechat_exp_2.10.20260925_2.exe`** 提取密钥并解密数据库
- 读取选中对象的名称、备注、聊天记录
- **实时更新**：定时轮询（如每 30 秒）调用一次解密和读取
- 支持 QQ 聊天记录读取（如有对应工具，同样方式集成）

#### 模块 5：LLM API Key 配置

- 弹出对话框，支持选择 DeepSeek、ChatGPT、Qwen、文心一言、Gemini、Claude
- 用户输入 API Key，程序自动检测可用性
- 可用则调用该平台**价格最低的模型**；不可用则提示

#### 模块 6：LLM 任务提取

- 将聊天内容发送给 LLM，要求提取：
  - 任务名称（无则自动起名，风格参考 DeepSeek 网页）
  - 任务主题
  - 任务类型（表单填写、材料提交、报名等）
  - 发布人（最早发布者，优先姓名）
  - 负责人（组织）
  - 起始/终止时间
  - 所需材料
  - 接头人
- 输出为结构化 JSON

#### 模块 7：任务去重与合并

- 每获取一个新任务，与已有任务实时对比
- 判定为同一任务时，合并发布人列表（含群聊），缩略图不展示多发布人

#### 模块 8：UI 主界面

- **整体风格**：暗色调，参考 Chrome 黑色主题，平面化，标签页化
- **布局**：左侧类别栏（进行中/未开始/已完成/已过期），右侧任务磁贴区
- **磁贴**：类似 Win10 开始菜单动态磁贴，支持拖拽、网格对齐
- **交互**：
  - 悬停：略微放大 + 白色包边
  - 悬停底部显示“完成”（绿）和“删除”（红）按钮
  - 长按 2.5 秒生效，显示进度条（参考《战锤40K：星际战士2》购买进度条）
  - 点击进入详情：显示原文、材料清单、可点击链接（用对应账号登录后打开）
- **右上角账户按钮**：悬停显示已登录平台及账号数，点击进入账户管理

#### 模块 9：任务状态管理

- 初始化：根据起止时间和当前时间（UTC+8）标记为“未开始/进行中/已过期”
- 人工确认：长按“完成”标记已完成；长按“删除”删除任务及后台数据
- 自动修改：实时检测时间，重新标记分类

#### 模块 10：加密与安全

- 所有敏感信息（账号、密钥、聊天数据）使用 **PBKDF2** 加密存储
- 数据库文件加密，防止外部读取

### 开发要求

1. **代码结构清晰**：模块化，便于后续维护和调试
2. **UI 流畅**：支持 2560×1600、1920×1080 等高分辨率
3. **错误处理**：所有外部调用（wechat_exp、LLM API）需有超时和异常处理
4. **日志系统**：记录关键操作和错误，便于调试
5. **可测试性**：提供模拟数据模式，无需真实微信环境即可测试 UI
