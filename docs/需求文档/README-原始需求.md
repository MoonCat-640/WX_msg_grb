# 微信消息任务汇总器与展示台

本软件（下面简称“该软件”）运行在Windows电脑上，本地运行，可以读取用户选定的微信和QQ群的信息，并从中提取聊天中发布的任务（包括他人发布的消息和自己发布的消息），汇总后以类似Windows10开始菜单的动态磁贴的方式展示在UI界面中，展示任务的名称、主题、类型、起始和终止时间、发布人及所在群聊。点击磁铁进入任务后可以查看任务详情，包括需要填写的表格、共享表格、问卷、线上问卷和需要上交的材料、任务地点和参与人员等

# 软件功能

## 0、安装

用户双击运行该软件离线安装包的Setup.exe程序，Setup.exe通过UAC询问用户并获取管理员权限，启动安装引导，选择安装过程中的语言后，选择软件本体的安装位置，并敲定安装的细节（例如为当前用户安装还是为全体用户安装，是否添加到PATH等），进行安装，安装完成后，生成指向该软件实际运行程序（WX_msg_grb.exe）的快捷方式，双击快捷方式后即可打开软件。

## 1、登录微信、QQ

打开客户端后，选择登录微信、QQ、企业微信三个主流社交平台（支持3个平台的账号同时登录），其中，微信支持手机微信扫码登录；QQ支持手机QQ扫码登录、填写账号密码登录；企业微信支持手机企业微信扫码登录。

用户可以选择登录1、2、3个平台，每个平台不多于2个账号，登录完后点击“完成”按钮，完成登录和账号信息的获取，或在登录的任意过程点击“取消”按钮取消登录，退出该软件。

登录后，对已登录的个人账号信息进行加密，使用**PBKDF2算法** 进行加密存储，防止被外界通过网络连接破解。

## 2、选择联系人和群聊

登录完成后，该软件自动识别登录了几个平台的账号几个账号，并以可选标签页的形式展示每个账号中的联系人和群聊。用户通过点击的方式选择每个平台每个账户中的一个或多个联系人和群聊。

## 3、读取选中联系人、群聊的聊天信息

用户完成聊天对象的选定后，该软件自动读取所选中的对象的名称、备注和聊天记录，并在运行过程中实时更新读取的聊天记录

## 4、获取用户AI平台的API Key

完成信息的读取后，弹出提示框，让用户选择使用的LLM（支持Deepseek、chatGPT、Qwen、文心一言、Gemini、Claude六个平台），并输入API Key，该软件自动检测API Key是否可用，对于可用的，调用对应平台价格最低的模型，对于不可用的，弹出提示框告知用户该API Key不可用。

## 5、调用LLM分析聊天内容

调用第4步获取的LLM，分析第3步中获取的聊天内容，从中提取到任务发布的信息，包括：

任务名称、任务主题、任务类型、发布人（及所在群聊）、负责人（组织）、起始和终止时间、所需材料、接头人。其中，如果没有明确的任务名称、主题，则调用LLM自己起名，要求直观（参考Deepseek官方网页给聊天的起名），任务类型需要自己总结，包括表单填写、材料提交、报名等。发布人为最早发布该任务的用户（提取其备注或群昵称，优先找该用户的姓名），并汇总出材料清单

## 6、任务信息的对比

由于多个群中可能同时由相同、不同用户发布同一个任务信息，因此获取到任务信息后需要进行比对（每获取一个都与先前获取到的信息进行实时对比），如果任务相同，则仅在任务详情的发布人一栏将所有发布该任务的人（及所在群聊）显示，缩略中不显示

## 7、任务信息的呈示

在UI的主界面任务区中，用类似Windows10开始菜单动态磁贴的方式展示任务缩略信息，包括任务名称、主题、类型、负责人、其实和终止时间。磁贴可以拖动，但放置有网格（类似Windows10开始菜单动态磁贴的交互方式），当鼠标指针移动到某任务磁贴上时，该磁贴略微放大，并从无明显包边变为有白色包边以提示用户，单击进入任务后，会显示任务发布的原文和材料清单（包括填写的共享表格链接、线上问卷、普通表格和文档等，其中涉及线上链接的，单击链接进入后，该程序直接使用获取该任务的账号进行登录）

## 8、任务状态的确认

### 1、初始化

根据任务的起始和终止时间，并获取电脑现在的时间（UTC+8:00），将任务初始化分类标记为“未开始”“进行中”“已过期”3种状态。该步骤需要在运行过程中实时检测和操作

### 2、人工确认

在鼠标移动到某磁贴上时，除了进行第7步中提到的变化，还需要在底部显示2个按钮（原来没有）：完成 和 删除，分别使用绿色系和红色系颜色，若点击完成，则该任务标记为“已完成”；若点击“删除”，则不再显示，并删除后台中关于该任务的存储信息。无论按下哪个按键，都需要长按2.5秒方可真正生效，会显示进度条（参考游戏《战锤40,000:星际战士2》中购买物品的进度条）

### 3、自动修改

参考“1、初始化”中的内容，实时检测任务的时间状态，并重新标签，分类

# UI设计

1、整体使用暗色调，参考Google Chrome黑色主题，观感现代，操作流畅，合乎逻辑，设计平面化，标签页化

2、主界面分为2栏，参考deepseek聊天官网的风格，左侧小栏为类别区，按上面所述显示4个类别：“进行中”、“未开始”、“已完成”和“已过期”。右侧大栏为具体的任务区，选择某个类别后类似用Windows10开始菜单动态磁贴的风格展示该类别标签的任务

3、其余事项按照上述“软件功能”第7、8点进行设计

4、右上角为账户，平时为显示“My Account”字样的按钮，颜色比主题色略浅，鼠标移动到该按钮上后，渐显一个小框，显示已登录的平台和其账户数量，单击按钮后进入账户管理界面，可以选择退出某账号或添加登录账号

# 注意事项

1、对于所有敏感的且需要储存的信息，都应该进行加密以防止被破解。使用**PBKDF2算法** 。

2、要求对Windows10\11优化到位，像现代软件一样使用流畅，支持2560 * 1600、1920 * 1080等高分辨率，观感优雅
